# 🐉 Dragon Repeller

A lightweight, text-based RPG built with vanilla HTML, CSS, and JavaScript.
Explore the town, gear up, and fight your way through monsters to defeat the
dragon that is keeping everyone from leaving.

🔗 **Live demo:** (add your GitHub Pages link)

## 🎮 Features

- **Navigation:** Move between the Town Square, Store, and Cave using dynamic buttons.
- **Turn-based combat:** Fight a Slime, a Fanged Beast, and the Dragon boss.
  Attacks can hit or miss, and damage grows with your weapon and XP.
- **Economy:** Earn gold from battles, then buy health or stronger weapons.
- **Inventory:** Collect weapons, sell extras for gold, and watch out:
  weapons can break during fights.
- **Secret mini-game:** Find the hidden number-guessing game to win bonus
  gold or lose health.
- **Live stats:** XP, health, gold, and monster stats update instantly
  through DOM manipulation.
- **Replay:** Restart after winning or losing.

## 🛠️ Built With

- **HTML5:** page structure and game interface
- **CSS3:** styling and layout
- **JavaScript (ES6+):** game logic, state, event handling, DOM updates
